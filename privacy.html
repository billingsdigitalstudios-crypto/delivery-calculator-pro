Privacy Policy for Delivery Calculator Pro

Effective Date: June 2026

Billings Digital Studio ("we," "our," or "us") operates the Delivery Calculator Pro Chrome Extension. We value and respect your privacy.

1. Information Collection and Storage

Delivery Calculator Pro operates entirely within your local browser context. All configuration settings, pricing rules, mileage parameters, and localized text scripts are stored strictly on your device using the Chrome chrome.storage.local API framework. We do not run remote database tracking architectures, nor do we see, access, collect, or store your private data on external servers.

2. External Network Transfers

To compute travel logistics, the extension securely transmits routing string data (starting points and buyer zip codes) directly to the official Google Maps Distance Matrix API via secure HTTPS encryption protocol loops. This data transmission is strictly limited to obtaining routing metrics and is never retained or utilized for any secondary tracking mechanisms.

3. Data Monetization and Security

We do not sell, trade, rent, or lease user data to third-party data brokers, advertising agencies, or marketing systems. All transaction structures are securely handled by external payment infrastructure via Stripe.

4. Contact Us

For inquiries regarding this data protocol documentation, contact us directly via our official store support portal loop.
